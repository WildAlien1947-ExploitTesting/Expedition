# Expedition

## Run in GitHub Codespaces ONLY!!!

1. Open the [Expedition repository](https://github.com/WildAlien1947-ExploitTesting/Expedition) on GitHub.
2. Select **Code**, open the **Codespaces** tab, and choose **Create codespace on main**.
3. When the Codespace finishes loading, open its terminal and install the dependencies:

   ```sh
   npm install
   ```

4. Start the app:

   ```sh
   npm start
   ```

5. When Codespaces detects port **3000**, open it in your browser from the **Ports** tab.
